# Harrowgate Supply Co — Q4 depot issue reconciliation

This repository is the shared working area for the Q4 stock-issue reconciliation.

- `depots/<depot>/` — each depot's hand-maintained issue sheets, field notes and
  local operational files. Layouts differ from depot to depot; read each file as
  it is written.
- `reference/conversion_factors.json` — unit conversion table.
- `reference/output_template.json` — required shape of the reconciliation report.
- `reference/remark_index.md` — index of open audit remarks (see the note inside).

The finance team expects the completed reconciliation report at
`reports/q4_issue_reconciliation.json` on the default branch.
